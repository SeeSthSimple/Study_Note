## 一、空指针导致测试失败

### 对nullptr的全使用问题

  **1. NXUFUN专用垃圾桶安全接收底层API废弃输出**
  ``` c
// =========================================================
// NX UFUN 专用“垃圾桶”对象：用于安全接收底层 API 的废弃输出
// 优势：按需创建，离开作用域自动释放，线程安全
// =========================================================
struct UfunDummy {
    double d_val = 0.0;
    int i_val = 0;
    double vec3[3] = {0.0, 0.0, 0.0};
    char str[256] = {0};
    tag_t tag_val = NULL_TAG;

    // 默认构造函数，创建时自动清零
    UfunDummy() = default; 
};
  ```
  **2. 针对UF会话**
  - UF_terminate() 把 UF 会话关掉，Python 侧后续 nx_openpart 的状态就不再可靠。
  - 如果脚本复用同一会话但不重新载入/还原模型，前一次对齐改变了实体坐标，后续对齐自然会失败或评分异常。
