# Embedded Q&A Records

This folder stores one note file per user question.

## Long-term Note Policy

From now on, every new user question should be recorded here as a study note.

Rules:

1. One question -> one standalone note file.
2. Keep notes grouped by module/topic in the title and body (for example: `interrupt`, `freertos`, `ota`, `uart`, `power`, `gpio`).
3. Notes should be written in a practical, project-ready style (concept -> code -> pitfalls -> checklist).
4. If a new question extends an existing topic, still create a new dated note and cross-reference related notes.
5. Treat this folder as the user's long-term learning notebook.

## Naming Convention

- `YYYY-MM-DD-001-topic.md`
- `YYYY-MM-DD-002-topic.md`

## Note Template

Each file should include:

1. Original question
2. Organized explanation
3. Key points
4. Practical notes if needed

## Workflow

For each new embedded-systems question:

1. Summarize and organize the question
2. Write the answer as a standalone note
3. Save it as a new Markdown file in this folder
4. Add module context and practical action items for direct hands-on use
