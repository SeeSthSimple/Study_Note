# 硬件-PCB基础与布局约束

## 原始问题

PCB 层叠结构怎么设计？去耦电容为什么必须靠近芯片引脚放？高速信号走线有哪些规则？为什么要铺地平面？过孔对信号有什么影响？EMC 基本原则是什么？软件工程师需要懂多少 PCB 知识？

## 先给结论

PCB 基础的核心是"物理布局决定了信号质量、电源质量和电磁兼容性"：

1. 层叠设计决定了阻抗控制和电源分配，是 PCB 设计的骨架。
2. 去耦电容的位置和数量直接影响电源稳定性，放远了等于没放。
3. 高速信号走线规则（阻抗控制、差分等长、避免跨分割）保障信号完整性。
4. 完整的地平面提供低阻抗返回路径，是信号质量和 EMC 的基础。
5. 软件工程师不需要画 PCB，但需要理解布局约束对软件行为的影响。

如果只知道"PCB 就是绿板子"，但讲不清层叠结构、去耦电容位置、走线规则和 EMC 基础，就很难理解为什么某些硬件问题"换个板子就好了"。

## 这个知识解决什么问题

这篇笔记主要解决下面几类问题：

1. 看到 PCB 上的器件布局和走线，不理解为什么这样放、这样走。
2. 不理解去耦电容为什么要靠近引脚，放远一点会怎样。
3. 面试时被问"PCB 层叠怎么设计"，不知道怎么回答。
4. 不理解为什么某些信号走线有严格的等长和间距要求。
5. 遇到 EMC 问题时不知道从哪里排查。

它在 AI 时代依然重要，因为 AI 能帮你写驱动和设备树，但当板子有 EMC 问题、电源噪声大、高速信号不稳定时，AI 无法帮你分析 PCB 布局问题。理解 PCB 基础后，你才能在"软件没问题但硬件不稳定"时，把怀疑方向转向 PCB 设计。

## 核心概念 / 本质机制

### 1. PCB 层叠结构

PCB 由多层铜箔和介质材料交替叠压而成：

```text
4 层板典型层叠:

顶层 (Top Layer):    信号层 + 器件放置
内层1 (Inner1):      地平面 (GND)
内层2 (Inner2):      电源平面 (VCC)
底层 (Bottom Layer): 信号层 + 器件放置
```

```text
6 层板典型层叠:

顶层:     信号层
内层1:    地平面
内层2:    信号层 (高速信号)
内层3:    信号层 (高速信号)
内层4:    电源平面
底层:     信号层
```

层叠设计原则：

1. 信号层紧邻参考平面（地或电源），确保阻抗可控。
2. 高速信号放在内层，夹在地和电源平面之间，减少 EMI。
3. 地平面和电源平面尽量靠近，形成平面电容，改善高频去耦。
4. 对称层叠避免 PCB 翘曲。

### 2. 不同层数的适用场景

| 层数 | 成本 | 适用场景 |
| --- | --- | --- |
| 2 层 | 最低 | 简单 MCU 板、低速信号 |
| 4 层 | 中等 | 大多数嵌入式板、有高速信号 |
| 6 层 | 较高 | 复杂 SoC 板、DDR + 高速接口 |
| 8 层+ | 高 | 多电源域、多高速接口、严格 EMC |

2 层板 vs 4 层板的关键差异：

1. 2 层板没有完整地平面，信号返回路径差，EMI 难控制。
2. 4 层板有完整地平面，阻抗可控，EMI 容易控制。
3. 有高速信号（SPI > 25MHz、DDR、USB）的板子，强烈建议 4 层以上。

### 3. 去耦电容

去耦电容的作用：

1. **提供瞬态电流**：芯片切换时需要瞬间大电流，电源来不及响应，去耦电容就近提供。
2. **滤除高频噪声**：抑制电源线上的高频纹波。
3. **降低电源阻抗**：在特定频率范围内降低电源分配网络的阻抗。

为什么必须靠近引脚放：

```text
电容到芯片引脚之间有走线电感:

  电容 ---[走线电感]--- 芯片引脚

走线电感 ≈ 1nH/mm

如果电容距离引脚 20mm:
  走线电感 ≈ 20nH
  电容谐振频率偏移，高频去耦效果大幅下降

如果电容距离引脚 2mm:
  走线电感 ≈ 2nH
  高频去耦效果好
```

去耦电容的放置规则：

1. 每个电源引脚旁放一个 100nF 陶瓷电容，距离 < 5mm。
2. 每组电源引脚放一个 1~10μF 钽电容或大容量陶瓷电容。
3. 电容的接地端直接连到地平面（过孔紧挨焊盘）。
4. 多个容值搭配使用：100nF（高频）+ 1μF（中频）+ 10μF（低频）。

### 4. 阻抗控制走线

高速信号走线需要控制特性阻抗：

```text
50Ω 单端走线 (FR4, 4层板):
  线宽 ≈ 0.15mm (6mil)，距参考平面 0.1mm

100Ω 差分走线 (FR4, 4层板):
  线宽 ≈ 0.1mm (4mil)，间距 ≈ 0.1mm (4mil)
```

阻抗控制的要求：

1. PCB 制造商需要知道阻抗要求和容差。
2. 制造商会根据层叠参数调整线宽。
3. 出厂前会用 TDR（时域反射计）抽检阻抗。
4. 阻抗偏差通常要求 ±10%，高速接口可能要求 ±5%。

### 5. 差分走线规则

```text
差分对走线要求:

1. 等长: 两根线长度差 < 5mil (0.127mm)
   - USB 2.0: < 150mil
   - USB 3.0: < 5mil
   - DDR 时钟: < 10mil
   - PCIe: < 5mil

2. 等距: 两根线间距保持一致
   - 间距变化 → 阻抗变化 → 反射

3. 紧耦合: 间距 ≈ 线宽
   - 太远 → 共模抑制能力下降

4. 同层: 两根线在同一层
   - 换层 → 过孔不连续性

5. 同过孔: 换层时两个过孔紧挨着
   - 保证返回路径对称
```

蛇形走线（等长匹配）：

```text
当两根差分线长度不等时，短的那根需要绕蛇形:

  D+ ──────────────────────
                           │
  D- ──────┐              │
            │              │
            └──────────────┘

蛇形走线的规则:
1. 绕线间距 ≥ 3 倍线宽 (避免自串扰)
2. 绕线长度精确计算
3. 绕线位置尽量靠近不匹配点
```

### 6. 过孔

过孔（Via）是连接不同层的导电孔：

```text
过孔结构:
  顶层焊盘
    |
  过孔壁 (镀铜)
    |
  内层连接 (如果该层需要连接)
    |
  底层焊盘

过孔类型:
  通孔 (Through-hole): 穿透所有层
  盲孔 (Blind): 从外层到内层，不穿透
  埋孔 (Buried): 只在内层之间
```

过孔对信号的影响：

1. 过孔有寄生电感（约 0.5~1nH）和寄生电容（约 0.3~0.8pF）。
2. 过孔引起阻抗不连续，产生反射。
3. 高速信号换层时，过孔旁边必须加地过孔提供返回路径。

地过孔（Stitching Via）的规则：

```text
信号过孔旁边放地过孔:

  信号过孔    地过孔
     ○         ●
     │         │
     │         │
     ○         ●

地过孔提供返回路径从一层切换到另一层

典型配置:
  1 个信号过孔 + 1~2 个地过孔
  地过孔距离信号过孔 < 50mil
```

### 7. 地平面

完整地平面的作用：

1. **低阻抗返回路径**：高频信号的返回电流紧贴走线下方的地平面流动。
2. **阻抗参考**：走线的特性阻抗以地平面为参考。
3. **屏蔽**：地平面隔离不同层的信号，减少串扰。
4. **EMC**：低阻抗返回路径减小环路面积，降低辐射。

地平面分割的规则：

1. 高速信号下方不要分割地平面。
2. 如果必须分割（如模拟地和数字地），只在一点连接。
3. 分割处加磁珠或 0Ω 电阻，不要直接断开。
4. 绝对不要让高速信号跨越地平面分割。

### 8. 电源平面

电源平面的作用：

1. 低阻抗供电，减少压降。
2. 与地平面形成平面电容，提供高频去耦。
3. 作为信号走线的参考平面（仅次于地平面）。

电源平面分割：

```text
一块电源平面可以分成多个区域:

  ┌──────────┬──────────┐
  │  VDD_3V3 │  VDD_1V8 │
  │          │          │
  ├──────────┼──────────┤
  │  VDD_DDR │  VDD_PHY │
  │          │          │
  └──────────┴──────────┘

分割规则:
1. 不同电压区域之间留足够间距 (> 20mil)
2. 高速信号不要跨越分割线
3. 分割线尽量窄，减少对地平面完整性的影响
```

### 9. EMC 基础

EMC（电磁兼容性）包括 EMI（电磁干扰发射）和 EMS（电磁抗扰度）：

EMI 的主要来源：

1. **差模辐射**：信号环路产生的辐射，环路面积越大辐射越强。
2. **共模辐射**：电缆和走线上的共模电流产生的辐射，频率越高辐射越强。

降低 EMI 的基本方法：

1. 减小信号环路面积：完整地平面 + 走线紧贴地平面。
2. 降低信号边沿速率：GPIO 输出速度不要设太高。
3. 使用差分信号：差分对的辐射相互抵消。
4. 加去耦电容：减少电源线上的高频噪声。
5. 电缆加磁珠和共模电感：抑制共模辐射。
6. 屏蔽罩：对强辐射源加金属屏蔽。

### 10. 软件工程师需要关注的 PCB 知识

软件工程师不需要画 PCB，但需要理解：

1. **为什么某些信号不能随意提高频率**：走线长度和阻抗限制了最高频率。
2. **为什么 GPIO 输出速度要合理选择**：不是越快越好，太快会增加 EMI 和反射。
3. **为什么换板子可能解决问题**：PCB 批次差异可能导致 SI 和 EMC 问题。
4. **为什么某些接口的走线长度有限制**：阻抗匹配和时序约束。
5. **为什么电源噪声会导致软件偶发错误**：电源纹波可能导致芯片瞬间工作异常。

## 数据流 / 控制流 / 时序关系

### PCB 设计影响软件行为的路径

```text
PCB 设计问题
  |
  ├─→ 电源噪声大 → 芯片瞬间复位或寄存器写入失败 → 软件偶发错误
  |
  ├─→ 信号完整性差 → 高速总线误码 → 驱动读到错误数据
  |
  ├─→ 串扰严重 → 相邻信号互相干扰 → 特定数据模式出错
  |
  ├─→ EMI 超标 → 干扰其他设备或被认证拒绝 → 产品无法上市
  |
  └─→ 返回路径不连续 → 信号质量下降 → 降低频率才能稳定工作
```

### 去耦电容的电流供应时序

```text
芯片电流需求突变 (如从 10mA 跳到 200mA)
  |
  V  (< 1ns)
最近的 100nF 电容提供瞬态电流
  |  (有效频率: 1MHz~100MHz)
  |
  V  (几个 ns)
1μF 电容接力提供电流
  |  (有效频率: 100kHz~10MHz)
  |
  V  (几十个 ns)
10μF 电容接力提供电流
  |  (有效频率: 10kHz~1MHz)
  |
  V  (μs 级)
DCDC/LDO 响应，稳定输出
```

如果最近的 100nF 电容放远了，瞬态电流供应不上，电源电压会瞬间跌落。

## 最小可运行示例

### 检查 PCB 布局的软件辅助方法

```c
/* 通过读取芯片 ID 寄存器验证供电是否稳定 */
/* 如果读到的 ID 值偶尔出错，可能是电源去耦不足 */

#include <linux/io.h>
#include <linux/module.h>
#include <linux/delay.h>

static int check_power_stability(void __iomem *base)
{
    u32 id;
    int i, err_count = 0;

    for (i = 0; i < 1000; i++) {
        id = readl(base + 0x00);
        if (id != 0x12345678)
            err_count++;
        udelay(100);
    }

    if (err_count > 0)
        pr_warn("ID 寄存器读取 %d 次错误，可能电源去耦不足\n", err_count);
    else
        pr_info("ID 寄存器读取稳定，电源质量良好\n");

    return err_count;
}
```

### GPIO 输出速度选择示例

```c
/* 根据 PCB 走线长度选择 GPIO 输出速度 */

static void config_gpio_speed(int pin, int trace_length_mm)
{
    uint32_t speed;

    if (trace_length_mm < 10) {
        speed = GPIO_OSPEEDR_VERY_HIGH;
    } else if (trace_length_mm < 30) {
        speed = GPIO_OSPEEDR_HIGH;
    } else if (trace_length_mm < 80) {
        speed = GPIO_OSPEEDR_MEDIUM;
    } else {
        speed = GPIO_OSPEEDR_LOW;
    }

    set_gpio_speed(pin, speed);
}
```

### 设备树中与 PCB 相关的配置

```dts
/* SPI 最大频率受 PCB 走线长度限制 */
/* 走线 < 3cm: 可达 50MHz */
/* 走线 3~10cm: 建议 ≤ 25MHz */
/* 走线 > 10cm: 建议 ≤ 10MHz */

&spi0 {
    status = "okay";
    spi-max-frequency = <25000000>;  /* 根据 PCB 走线长度设定 */

    flash@0 {
        compatible = "jedec,spi-nor";
        reg = <0>;
        spi-max-frequency = <25000000>;
    };
};
```

## 代码解读

### 1. 为什么 ID 寄存器读取错误可能指向 PCB 问题

ID 寄存器是芯片的固定值，正常情况下每次读取应该相同。如果偶尔读到错误值，说明芯片在读取瞬间供电不足或信号不稳定，这通常指向去耦电容不足或走线太长。

### 2. 为什么 SPI 最大频率要根据走线长度设定

走线越长，信号的传播延迟和反射影响越大。25MHz 的 SPI 时钟周期是 40ns，如果走线延迟 + 反射稳定时间超过 20ns（半个周期），信号质量就无法保证。走线越长，能稳定工作的最高频率越低。

### 3. 为什么这个检查要循环 1000 次

电源去耦不足导致的问题通常是偶发的，单次读取可能正常。循环 1000 次增加捕获瞬态错误的概率。如果 err_count > 0，说明存在电源瞬态问题。

## 正确写法 vs 常见错误写法

| 场景 | 正确做法 | 常见错误 | 为什么错 |
| --- | --- | --- | --- |
| 去耦电容 | 靠近引脚放，< 5mm | 放在板子边缘 | 走线电感大，高频去耦失效 |
| 地平面 | 保持完整 | 随意开槽分割 | 返回路径中断，EMI 增加 |
| 高速走线 | 阻抗控制 + 差分等长 | 随意走线 | 反射和时序问题 |
| 过孔换层 | 旁边加地过孔 | 只打信号过孔 | 返回路径不连续 |
| GPIO 速度 | 根据走线长度选择 | 全部最高速 | 不必要的 EMI 和反射 |
| SPI 频率 | 根据走线长度限制 | 直接设芯片最大频率 | 可能超出 PCB 能力 |
| 电源平面 | 高速信号不跨分割 | 信号随意跨分割 | 返回路径中断 |

## 边界条件与适用范围

1. 这篇笔记面向软件工程师的 PCB 基础入门，不是 PCB 设计专业课程。
2. 实际 PCB 设计需要 EDA 工具（Altium、Cadence、KiCad）和仿真工具。
3. 层叠设计和阻抗计算通常由硬件工程师或 SI 工程师完成。
4. 软件工程师的 PCB 知识主要用于：理解硬件约束、配合调试、审查设计。
5. 2 层板的设计约束比 4 层板严格得多，很多高速接口在 2 层板上难以实现。

## 常见坑与排查

| 现象 | 常见 PCB 根因 | 优先验证方法 |
| --- | --- | --- |
| 芯片随机复位 | 去耦电容不足或太远 | 示波器看电源纹波和跌落 |
| 高速总线偶发误码 | 阻抗不匹配、走线太长 | 降低频率测试 |
| EMI 认证不过 | 地平面不完整、环路太大 | 近场探头扫描 |
| 差分信号不稳定 | 差分对不等长 | TDR 测量阻抗 |
| 特定位置信号差 | 过孔换层没加地过孔 | 检查 PCB 走线 |
| 电源噪声大 | 去耦电容位置不对 | 示波器看电源引脚噪声 |

### 推荐排查顺序

1. 先确认问题是否跟频率相关（降频后是否改善）。
2. 再用示波器看相关信号的波形质量。
3. 再检查 PCB 走线长度和阻抗控制。
4. 再检查去耦电容位置和数量。
5. 再检查地平面完整性。
6. 最后考虑 PCB 改版。

## 工程落地建议

### 1. 软件工程师审查 PCB 的关注点

```text
审查清单:
  [ ] 高速信号的走线长度是否合理？
  [ ] 差分对是否等长等距？
  [ ] 去耦电容是否靠近引脚？
  [ ] 地平面是否完整？
  [ ] 电源平面分割是否合理？
  [ ] 连接器引脚分配是否方便软件控制？
```

### 2. 和硬件工程师协作的要点

1. 提前告知 GPIO 分配和信号方向，避免关键信号走线过长。
2. 提前告知 SPI 频率需求，让硬件做阻抗控制。
3. 调试时提供详细的错误现象和触发条件。
4. 配合做降频测试和眼图测试。

### 3. PCB 改版时的软件验证

```text
新版 PCB 到手后:
1. 先验证基本功能（点灯、串口输出）
2. 再验证电源质量（读 ID 寄存器、量纹波）
3. 再验证高速接口（SPI、DDR、USB）
4. 再跑长时间稳定性测试
5. 最后做 EMC 预测试
```

## 性能、稳定性、可维护性影响

1. PCB 设计直接决定系统的信号质量和 EMC 性能，是硬件稳定性的基础。
2. 去耦电容不足是偶发错误的常见根因，极难通过软件排查。
3. 不合理的走线限制了最高工作频率，影响性能上限。
4. EMI 问题可能导致产品无法通过认证，延迟上市时间。
5. 良好的 PCB 设计让软件调试更顺畅，减少"硬件问题软件背锅"的情况。

## 面试 / 问答怎么讲

### 30 秒版本

PCB 层叠设计决定阻抗控制和电源分配。去耦电容必须靠近芯片引脚，放远了走线电感大，高频去耦失效。高速信号要做阻抗控制和差分等长。完整地平面提供低阻抗返回路径，是信号质量和 EMC 的基础。

### 3 分钟版本

从层叠结构讲起：4 层板是嵌入式的主流，信号-地-电源-信号。然后讲去耦电容：芯片切换需要瞬态电流，电容必须近放才能及时供应。再讲高速走线规则：阻抗控制、差分等长、避免跨分割。再讲地平面：完整地平面提供返回路径，分割会中断返回路径增加 EMI。最后讲软件工程师需要关注的点：GPIO 速度选择、SPI 频率限制、降频测试。

### 10 分钟版本

可以系统展开：先讲层叠设计的原理和不同层数的适用场景。然后详细讲去耦电容的电流供应机制和放置规则。再讲阻抗控制走线的计算方法和制造要求。再讲差分走线的等长匹配和蛇形绕线。再讲过孔的寄生效应和地过孔的必要性。再讲地平面和电源平面的设计规则。最后讲 EMC 基础和软件工程师的 PCB 知识边界。

## 实战练习

1. 拿一块开发板，数一下 PCB 层数，找到地平面和电源平面。
2. 找到 SoC 旁边的去耦电容，测量它们到电源引脚的距离。
3. 找到一对差分走线（USB 或 HDMI），观察是否等长等距。
4. 用示波器测量一个高速信号的波形，对比走线长和走线短的差异。
5. 故意降低 SPI 频率，观察通信稳定性是否改善。

## 关键要点

1. PCB 层叠设计是骨架，4 层板是嵌入式主流（信号-地-电源-信号）。
2. 去耦电容必须靠近引脚（< 5mm），放远了走线电感大，高频去耦失效。
3. 高速信号要做阻抗控制，差分信号要等长等距同层。
4. 完整地平面是信号质量和 EMC 的基础，不要随意分割。
5. 过孔换层时旁边要加地过孔，提供返回路径。
6. GPIO 输出速度不是越快越好，要根据走线长度选择。
7. 软件工程师的 PCB 知识主要用于理解约束、配合调试、审查设计。
