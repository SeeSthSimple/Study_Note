# 硬件-热设计基础

## 原始问题

芯片为什么会过热？热阻是什么？结温怎么计算？散热片怎么选？什么时候需要风扇？软件怎么监控温度和做热保护？过热降频的原理是什么？

## 先给结论

热设计的核心是"芯片产生的热量必须及时散出去，否则结温超过极限就会损坏或降频"：

1. 芯片功耗全部变成热量，热量从芯片结（Junction）通过封装到环境（Ambient），路径上每一步都有热阻。
2. 结温 Tj = Ta + P × θja，其中 Ta 是环境温度，P 是功耗，θja 是结到环境的热阻。
3. 如果 Tj 超过芯片的最大结温（通常 125°C 或 150°C），芯片可能损坏或触发热保护。
4. 散热方法：PCB 铜皮散热（小功率）、散热片（中等功率）、风扇（大功率）。
5. 软件通过温度传感器监控结温，超过阈值时降频降压（Thermal Throttling）保护芯片。

如果只知道"芯片会发热"，但讲不清热阻计算、结温估算、散热方案选择和热保护机制，就还没有真正理解热设计基础。

## 这个知识解决什么问题

这篇笔记主要解决下面几类问题：

1. 不知道芯片会不会过热，不会估算结温。
2. 不理解热阻参数的含义，看数据手册不知道怎么用。
3. 不知道什么时候需要加散热片，什么时候 PCB 铜皮就够了。
4. 面试时被问"过热保护怎么做"，只会说"降频"。
5. 不理解 Linux thermal 框架和热保护策略。

它在 AI 时代依然重要，因为 AI 能帮你优化代码性能，但性能优化的代价往往是更高的功耗和温度。理解热设计后，你才能在"性能拉满但芯片过热"和"性能受限但温度安全"之间做出合理权衡。

## 核心概念 / 本质机制

### 1. 热的基本概念

热的传递有三种方式：

1. **传导**：热量通过固体材料传递（芯片 → 封装 → PCB → 散热片）。
2. **对流**：热量通过流体（空气）传递（散热片 → 空气）。
3. **辐射**：热量通过电磁波传递（所有表面都在辐射，但通常占比小）。

嵌入式系统中，传导和强制对流（风扇）是主要散热方式。

### 2. 热阻

热阻是热量传递路径上的"阻力"，类似于电阻：

```text
热阻类比:
  电压差 → 温差 (ΔT)
  电流   → 热流 (功耗 P)
  电阻   → 热阻 (θ)

欧姆定律类比:
  V = I × R
  ΔT = P × θ
```

热阻的单位是 °C/W，表示每瓦功耗产生的温差。

### 3. 热阻参数

芯片数据手册中常见的热阻参数：

| 参数 | 含义 | 典型值 |
| --- | --- | --- |
| θja (RθJA) | 结到环境的热阻 | 20~100°C/W |
| θjc (RθJC) | 结到外壳的热阻 | 1~10°C/W |
| θjb (RθJB) | 结到 PCB 的热阻 | 5~30°C/W |
| ψjt | 结到外壳顶部的特征参数 | 0.5~5°C/W |

θja 是最常用的参数，但也是最容易误用的：

1. θja 是在标准测试板（JEDEC 标准）上测量的，实际 PCB 可能差异很大。
2. 实际 θja 取决于 PCB 铜皮面积、层数、风道、周围器件等。
3. 用 θja 估算结温时，结果只是近似值，需要留裕量。

### 4. 结温计算

```text
基本公式:
  Tj = Ta + P × θja

其中:
  Tj: 结温 (Junction Temperature)
  Ta: 环境温度 (Ambient Temperature)
  P:  芯片总功耗
  θja: 结到环境的热阻

示例:
  Ta = 40°C (工业级环境温度)
  P = 2W
  θja = 30°C/W

  Tj = 40 + 2 × 30 = 100°C

  如果芯片最大结温 = 125°C，裕量 = 25°C，基本安全
  如果芯片最大结温 = 105°C，裕量 = 5°C，太紧张
```

有散热片时的计算：

```text
Tj = Ta + P × (θjc + θcs + θsa)

其中:
  θjc: 结到外壳热阻 (芯片数据手册)
  θcs: 外壳到散热片热阻 (导热硅脂/导热垫，通常 0.2~1°C/W)
  θsa: 散热片到环境热阻 (散热片数据手册)

示例:
  Ta = 40°C
  P = 5W
  θjc = 2°C/W
  θcs = 0.5°C/W (导热硅脂)
  θsa = 5°C/W (小型散热片)

  Tj = 40 + 5 × (2 + 0.5 + 5) = 40 + 37.5 = 77.5°C
  裕量充足
```

### 5. 芯片的最大结温

| 等级 | 最大结温 | 说明 |
| --- | --- | --- |
| 商业级 | 0~70°C (环境) | 室内使用 |
| 工业级 | -40~85°C (环境) | 工业环境 |
| 汽车级 | -40~125°C (环境) | 车载 |
| 军品级 | -55~125°C (环境) | 军事应用 |

芯片内部结温限制通常为 125°C 或 150°C，少数汽车级芯片可达 175°C。

### 6. 散热方案选择

| 方案 | 适用功耗 | 热阻范围 | 成本 | 复杂度 |
| --- | --- | --- | --- | --- |
| PCB 铜皮散热 | < 1W | 30~100°C/W | 最低 | 最低 |
| 散热片 (自然对流) | 1~10W | 5~20°C/W | 低 | 低 |
| 散热片 + 风扇 | 5~50W | 1~5°C/W | 中 | 中 |
| 热管 + 风扇 | 20~100W | 0.5~2°C/W | 高 | 高 |
| 液冷 | > 100W | < 0.5°C/W | 最高 | 最高 |

#### PCB 铜皮散热

小功率芯片可以通过 PCB 铜皮散热：

```text
提高 PCB 散热能力的方法:
1. 芯片下方铺铜 (热焊盘)
2. 热焊盘打多个过孔连接内层铜皮
3. 顶层和底层铺大面积铜皮
4. 增加铜皮厚度 (2oz 替代 1oz)

热焊盘过孔规则:
  过孔数量: 4~9 个
  过孔直径: 0.3~0.5mm
  过孔间距: 1~2mm
  过孔壁镀铜: 增加导热
```

#### 散热片选型

散热片的关键参数：

1. **热阻 θsa**：越低散热能力越强。
2. **体积**：受机壳空间限制。
3. **风道**：自然对流还是强制风冷。
4. **安装方式**：导热胶、导热硅脂、卡扣、螺钉。

散热片热阻的经验估算：

```text
自然对流:
  小型散热片 (20×20×10mm): θsa ≈ 15~25°C/W
  中型散热片 (40×40×20mm): θsa ≈ 5~10°C/W
  大型散热片 (60×60×30mm): θsa ≈ 3~6°C/W

强制风冷 (1~2m/s 风速):
  热阻降低到自然对流的 1/3~1/2
```

### 7. 导热界面材料

芯片和散热片之间需要导热界面材料（TIM）填充微观间隙：

| 材料 | 导热系数 (W/mK) | 热阻 (°C/W) | 适用场景 |
| --- | --- | --- | --- |
| 导热硅脂 | 1~5 | 0.1~0.5 | CPU/GPU，需要薄涂 |
| 导热垫 | 1~6 | 0.5~2 | 填充较大间隙 |
| 导热胶 | 1~3 | 0.5~1.5 | 兼具粘接和导热 |
| 相变材料 | 3~8 | 0.05~0.2 | 高性能，薄且均匀 |
| 石墨片 | 5~15 (面内) | 0.1~0.5 | 横向导热，手机常用 |

### 8. 温度监控

嵌入式系统通常有多个温度传感器：

```text
SoC 内部温度传感器:
  - 通常在芯片内部靠近热点
  - 精度 ±2~5°C
  - 通过 ADC 读取或专用寄存器读取
  - Linux 中通过 thermal 子系统暴露

外部温度传感器:
  - NTC 热敏电阻 (便宜，需要 ADC)
  - 数字温度传感器 (如 LM75/TMP102，I2C 接口)
  - 热电偶 (高温场景)

典型监控点:
  - CPU 核心
  - DDR 颗粒
  - PMIC
  - 电源模块
  - 机壳表面
```

### 9. 热保护策略

#### 硬件级保护

1. **热关断（Thermal Shutdown）**：结温超过阈值时芯片自动关断，通常阈值 125~150°C。
2. **热告警（Thermal Warning）**：结温接近阈值时产生中断，软件可以采取措施。

#### 软件级保护

```text
Linux thermal 框架:

Trip Point 0 (被动): 75°C → 通知用户空间
Trip Point 1 (被动): 85°C → 开始降频
Trip Point 2 (被动): 95°C → 大幅降频 + 降压
Trip Point 3 (主动): 105°C → 开启风扇 (如果有)
Trip Point 4 (临界): 115°C → 紧急关机
```

#### 降频降压（Thermal Throttling）

```text
降频降压的原理:
  P_dynamic = α × C × V² × f

  降频 50%: 功耗降低约 50%
  降压 20%: 功耗降低约 36% (V² 效应)
  同时降频 50% + 降压 20%: 功耗降低约 68%

  降频降压后:
    功耗降低 → 发热减少 → 温度下降 → 芯片安全
    代价: 性能下降
```

### 10. Linux thermal 子系统

```dts
/* 设备树中的 thermal 配置 */
thermal-zones {
    cpu_thermal: cpu-thermal {
        polling-delay-passive = <100>;   /* 超过阈值后每 100ms 轮询 */
        polling-delay = <1000>;          /* 正常时每 1s 轮询 */

        thermal-sensors = <&tsadc 0>;

        trips {
            cpu_alert0: trip-point0 {
                temperature = <75000>;   /* 75°C */
                hysteresis = <2000>;     /* 回差 2°C */
                type = "passive";
            };
            cpu_alert1: trip-point1 {
                temperature = <95000>;   /* 95°C */
                hysteresis = <2000>;
                type = "passive";
            };
            cpu_crit: cpu-crit {
                temperature = <115000>;  /* 115°C */
                hysteresis = <0>;
                type = "critical";
            };
        };

        cooling-maps {
            map0 {
                trip = <&cpu_alert0>;
                cooling-device = <&cpu0 THERMAL_NO_LIMIT 2>;
            };
            map1 {
                trip = <&cpu_alert1>;
                cooling-device = <&cpu0 3 THERMAL_NO_LIMIT>;
            };
        };
    };
};
```

## 数据流 / 控制流 / 时序关系

### 热量传递路径

```text
芯片结 (热源)
  |
  V  θjc (1~10°C/W)
芯片外壳
  |
  V  θcs (0.2~1°C/W, 导热材料)
散热片
  |
  V  θsa (3~25°C/W, 自然对流/风冷)
环境空气

总热阻: θja = θjc + θcs + θsa
结温: Tj = Ta + P × θja
```

### 热保护的响应流程

```text
温度传感器读取结温
  |
  V
Tj < 75°C: 正常运行
  |
  V
Tj ≥ 75°C: 通知用户空间 (UI 显示温度警告)
  |
  V
Tj ≥ 85°C: 开始降频 (cpufreq 降低到 80%)
  |
  V
Tj ≥ 95°C: 大幅降频降压 (cpufreq 降低到 40%)
  |
  V
Tj ≥ 105°C: 开启风扇 (如果有)
  |
  V
Tj ≥ 115°C: 紧急关机 (kernel poweroff)
  |
  V
Tj ≥ 125°C: 硬件热关断 (芯片自动断电)
```

## 最小可运行示例

### 读取 SoC 温度

```c
#include <linux/thermal.h>

static int read_soc_temperature(void)
{
    struct thermal_zone_device *tz;
    int temp, ret;

    tz = thermal_zone_get_zone_by_name("cpu-thermal");
    if (IS_ERR(tz))
        return PTR_ERR(tz);

    ret = thermal_zone_get_temp(tz, &temp);
    if (ret)
        return ret;

    pr_info("CPU 温度: %d.%d°C\n", temp / 1000, (temp % 1000) / 100);
    return temp;
}
```

### 用户空间读取温度

```bash
cat /sys/class/thermal/thermal_zone0/temp
# 输出: 45000 (表示 45.000°C)

cat /sys/class/thermal/thermal_zone0/type
# 输出: cpu-thermal

cat /sys/class/thermal/thermal_zone0/trip_point_0_temp
# 输出: 75000 (75°C 告警阈值)
```

### 结温估算工具

```c
#include <stdio.h>

struct thermal_params {
    float ta;
    float power;
    float theta_jc;
    float theta_cs;
    float theta_sa;
};

float calc_junction_temp(struct thermal_params *p)
{
    float theta_ja = p->theta_jc + p->theta_cs + p->theta_sa;
    float tj = p->ta + p->power * theta_ja;
    return tj;
}

int main(void)
{
    struct thermal_params p = {
        .ta = 40.0f,
        .power = 3.0f,
        .theta_jc = 2.0f,
        .theta_cs = 0.5f,
        .theta_sa = 8.0f,
    };

    float tj = calc_junction_temp(&p);
    printf("结温: %.1f°C\n", tj);
    printf("热阻: %.1f°C/W\n", p.theta_jc + p.theta_cs + p.theta_sa);

    if (tj > 105.0f)
        printf("警告: 结温过高，需要改善散热！\n");
    else if (tj > 90.0f)
        printf("注意: 结温偏高，裕量不足\n");
    else
        printf("结温在安全范围内\n");

    return 0;
}
```

## 代码解读

### 1. 为什么 thermal_zone_get_temp 返回的单位是 milli-degree

Linux thermal 子系统统一使用毫度（millidegree）为单位，即 45000 表示 45.000°C。这样避免浮点运算，内核代码不使用浮点。

### 2. 为什么降频降压比单纯降频更有效

动态功耗 P = αCV²f，降频只降低 f（线性关系），降压降低 V²（二次方关系）。同时降频降压，功耗下降更快，降温效果更明显。

### 3. 为什么热保护要有回差（hysteresis）

如果没有回差，温度在阈值附近波动时，降频和恢复会频繁切换，导致性能抖动。回差确保温度降到阈值以下一定量后才恢复正常频率，避免频繁切换。

## 正确写法 vs 常见错误写法

| 场景 | 正确做法 | 常见错误 | 为什么错 |
| --- | --- | --- | --- |
| 结温估算 | 用 θjc + θcs + θsa 分别计算 | 直接用 θja | θja 是标准测试板值，实际差异大 |
| 散热片选型 | 根据功耗和热阻计算 | 凭感觉选 | 可能散热不足或浪费空间 |
| 导热硅脂 | 薄而均匀涂抹 | 涂很厚 | 硅脂导热率远低于金属，厚了反而热阻大 |
| 温度监控 | 多点监控 + 阈值告警 | 只看一个点 | 可能漏掉局部热点 |
| 热保护 | 多级降频 + 回差 | 只设一个关断阈值 | 关断前没有降频保护 |
| PCB 铜皮 | 热焊盘 + 多过孔 | 不铺铜 | 小功率芯片可能过热 |

## 边界条件与适用范围

1. 这篇笔记面向软件工程师的热设计入门，不是热设计工程师的专业课程。
2. 结温计算只是估算，实际温度受 PCB 布局、风道、周围器件等多种因素影响。
3. 精确的热仿真需要专业工具（Flotherm、Icepak），不在本篇范围。
4. 不同封装的热阻差异很大：QFP > QFN > BGA，BGA 的散热能力最强。
5. 瞬态功耗（如 burst 模式）的温升需要考虑热容，不能只用稳态热阻计算。

## 常见坑与排查

| 现象 | 常见热设计根因 | 优先验证方法 |
| --- | --- | --- |
| 芯片随机复位 | 过热触发热关断 | 读温度寄存器 |
| 性能偶发下降 | 过热降频保护 | cat /sys/.../temp |
| 芯片烫手 | 散热不足 | 红外热像仪或热电偶 |
| 长时间运行后出错 | 累积温升超预期 | 满载长时间测试 |
| 散热片效果差 | 导热材料没涂好 | 重新涂硅脂 |
| 特定位置芯片过热 | 风道被挡 | 检查机壳风道设计 |

### 推荐排查顺序

1. 先读芯片内部温度传感器，确认实际结温。
2. 再对比数据手册的最大结温，判断裕量。
3. 再检查散热方案是否匹配功耗。
4. 再检查导热材料是否正确安装。
5. 再检查风道和机壳设计。
6. 最后考虑增加散热片或风扇。

## 工程落地建议

### 1. 热设计检查清单

```text
设计阶段:
  [ ] 估算每个芯片的功耗
  [ ] 计算结温，确认裕量 > 20°C
  [ ] 选择散热方案
  [ ] PCB 预留散热铜皮和过孔
  [ ] 预留温度传感器位置

测试阶段:
  [ ] 满载运行 1 小时，监控各点温度
  [ ] 高温环境 (40~50°C) 下测试
  [ ] 验证热保护策略是否正常工作
  [ ] 检查降频后的性能是否可接受
```

### 2. 温度监控脚本

```bash
#!/bin/bash
while true; do
    for tz in /sys/class/thermal/thermal_zone*; do
        type=$(cat $tz/type 2>/dev/null)
        temp=$(cat $tz/temp 2>/dev/null)
        if [ -n "$temp" ]; then
            echo "$(date +%H:%M:%S) $type: $((temp/1000))°C"
        fi
    done
    sleep 5
done
```

```text
满载测试:
  CPU: stress-ng --cpu $(nproc)

  DDR: memtester 128M 3
  综合: 同时运行以上测试

监控:
  每秒记录温度、频率、功耗

```

## 性能、稳定性、可维护性影响

1. 过热是芯片早期失效的主要原因之一，每升高 10°C，寿命约减半。
2. 热保护降频会显著影响性能，需要在散热和性能之间权衡。
3. 良好的热设计让芯片在满载时也能稳定工作，减少因过热导致的性能波动。
4. 温度监控数据可以用于预测性维护，提前发现散热系统异常。
5. 热设计不足的产品在高温环境下会出现各种偶发问题，极难排查。

## 面试 / 问答怎么讲

### 30 秒版本

芯片功耗全部变成热量，结温 Tj = Ta + P × θja。如果结温超过芯片极限（通常 125°C），会触发降频或关断保护。散热方案从 PCB 铜皮到散热片到风扇，根据功耗选择。降频降压同时降低 V² 和 f，降温效果比单纯降频好。

### 3 分钟版本

从热阻讲起：θja 是结到环境的热阻，θjc 是结到外壳，θsa 是散热片到环境。结温 Tj = Ta + P × (θjc + θcs + θsa)。然后讲散热方案：小功率用 PCB 铜皮，中等功率加散热片，大功率加风扇。再讲热保护：多级降频 + 回差 + 最终关断。最后讲 Linux thermal 框架：trip point 定义阈值，cooling device 执行降频。

### 10 分钟版本

可以系统展开：先从热传递的三种方式讲起，引出热阻概念。然后详细讲结温计算方法和不同散热方案的选择。再讲导热界面材料的选型。再讲温度监控的硬件和软件实现。再讲 Linux thermal 子系统的架构和配置。最后讲热测试方法和常见热设计问题。

## 实战练习

1. 查一个 SoC 的数据手册，提取 θja 和 θjc，估算满载结温。
2. 在 Linux 系统上运行满载测试，用 `cat /sys/class/thermal/thermal_zone0/temp` 监控温度变化。
3. 计算一个 5W 芯片在 40°C 环境下需要的散热片热阻（目标结温 < 100°C）。
4. 修改设备树的 trip point 温度，观察降频行为。
5. 用红外热像仪或热电偶测量 PCB 上不同位置的温度分布。

## 关键要点

1. 结温 Tj = Ta + P × θja，必须低于芯片最大结温（通常 125°C）。
2. 热阻 θja = θjc + θcs + θsa，有散热片时分别计算更准确。
3. 散热方案：PCB 铜皮（< 1W）→ 散热片（1~10W）→ 风扇（5~50W）。
4. 导热硅脂要薄而均匀，厚了反而热阻大。
5. 热保护策略：多级降频 + 回差 + 最终关断。
6. 降频降压比单纯降频更有效（V² 效应）。
7. Linux thermal 子系统通过 trip point 和 cooling device 实现自动热管理。
