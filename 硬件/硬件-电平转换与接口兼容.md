# 硬件-电平转换与接口兼容

## 原始问题

3.3V 的 MCU 能不能直接接 5V 的传感器？1.8V 的 SoC 怎么跟 3.3V 的外设通信？电平转换芯片怎么选？什么时候可以直连，什么时候必须加转换？不同电压域的信号连接有哪些坑？

## 先给结论

电平转换的核心问题是"发送方的输出电平，接收方能不能正确识别"：

1. 如果发送方的 VOH > 接收方的 VIH，且发送方的 VOL < 接收方的 VIL，就能正确识别，可以直连。
2. 如果不满足，就需要电平转换。
3. 单向信号转换比双向简单，开漏信号比推挽信号好处理。
4. 选电平转换芯片时，要关注方向、速度、通道数、供电范围和传播延迟。

如果只知道"电压不同不能直接连"，但讲不清什么时候可以直连、什么时候必须转换、转换芯片怎么选，就还没有真正掌握电平转换与接口兼容。

## 这个知识解决什么问题

这篇笔记主要解决下面几类问题：

1. 不确定 3.3V 和 5V 系统能不能直连，怕烧芯片又怕过度设计。
2. 1.8V SoC 跟 3.3V 外设通信时不知道怎么处理。
3. 不知道电平转换芯片有哪些类型，怎么根据场景选型。
4. 面试时被问"3.3V MCU 能不能接 5V I2C 设备"，回答含糊。
5. 板级设计时不理解电源域划分和 IO 电压配置的关系。

它在 AI 时代依然重要，因为 AI 生成设备树和驱动代码时不会检查电平兼容性。理解电平转换后，你才能在原理图审查时发现"3.3V IO 直连 5V 输出"这类物理上不成立的连接，避免烧板子。

## 核心概念 / 本质机制

### 1. 电平兼容的判断条件

两个器件直连前，必须检查四个参数：

```text
发送方 VOH (输出高电平最小值)  >  接收方 VIH (输入高电平最小值)
发送方 VOL (输出低电平最大值)  <  接收方 VIL (输入低电平最大值)
```

如果两个条件都满足，就能正确通信。

### 2. 常见电平标准对比

| 标准 | VDD | VOH (min) | VOL (max) | VIH (min) | VIL (max) |
| --- | --- | --- | --- | --- | --- |
| 5V TTL | 5.0V | 2.4V | 0.4V | 2.0V | 0.8V |
| 3.3V LVTTL | 3.3V | 2.4V | 0.4V | 2.0V | 0.8V |
| 3.3V LVCMOS | 3.3V | 3.1V | 0.2V | 2.0V | 0.8V |
| 2.5V LVCMOS | 2.5V | 2.1V | 0.2V | 1.7V | 0.7V |
| 1.8V LVCMOS | 1.8V | 1.35V | 0.25V | 1.17V | 0.63V |

### 3. 常见组合的兼容性分析

#### 3.3V 输出 → 5V TTL 输入：✅ 可以直连

```text
3.3V LVTTL: VOH = 2.4V > 5V TTL: VIH = 2.0V ✓
3.3V LVTTL: VOL = 0.4V < 5V TTL: VIL = 0.8V ✓
```

3.3V 输出的高电平（2.4V 以上）足以被 5V TTL 输入识别为高。

#### 5V TTL 输出 → 3.3V LVTTL 输入：⚠️ 需要确认

```text
5V TTL: VOH = 2.4V > 3.3V LVTTL: VIH = 2.0V ✓
5V TTL: VOL = 0.4V < 3.3V LVTTL: VIL = 0.8V ✓
```

逻辑电平兼容，但 5V TTL 输出高电平可能达到 5V，3.3V 输入引脚能否承受 5V 取决于是否"5V 容忍"。

- 如果 3.3V IO 是 5V 容忍：可以直连。
- 如果不是 5V 容忍：需要电平转换或限流保护。

#### 5V CMOS 输出 → 3.3V 输入：❌ 不能直连

```text
5V CMOS: VOH ≈ 4.9V >> 3.3V IO 最大承受电压
```

5V CMOS 输出高电平接近 5V，远超 3.3V IO 的承受范围，会损坏芯片。

#### 1.8V 输出 → 3.3V 输入：❌ 不能直连

```text
1.8V LVCMOS: VOH = 1.35V < 3.3V LVTTL: VIH = 2.0V ✗
```

1.8V 输出的高电平不够高，3.3V 输入无法识别为高电平。

### 4. 电平转换的方法

#### 方法一：开漏 + 上拉（最简单的双向转换）

```text
3.3V 侧                          5V 侧
  |                                |
  +--- [4.7kΩ 上拉到 3.3V] ---+--- [4.7kΩ 上拉到 5V]
  |                             |
  开漏输出/输入                  开漏输出/输入
```

原理：

1. 任何一侧拉低，两侧都变低（线与逻辑）。
2. 两侧释放后，各自的上拉电阻拉到各自的 VDD。
3. 不需要额外的转换芯片。

适用条件：

1. 信号必须是开漏/开集输出。
2. 速度受上拉电阻和电容限制。
3. I2C 总线天然适合这种方式。

#### 方法二：电阻分压（最简单的单向降压）

```text
5V 输出 ---[R1]---+--- 3.3V 输入
                   |
                  [R2]
                   |
                  GND

Vout = Vin × R2 / (R1 + R2)

5V → 3.3V: R1 = 1kΩ, R2 = 2kΩ
  Vout = 5 × 2 / (1 + 2) = 3.33V
```

特点：

1. 只能单向降压，不能升压。
2. 便宜，只需要两个电阻。
3. 速度受 RC 时间常数限制，不适合高速信号。
4. 增加功耗和输出阻抗。

#### 方法三：MOSFET 电平转换（双向、常用）

```text
3.3V 侧                          5V 侧
  |                                |
  +--- [10kΩ 上拉到 3.3V]         +--- [10kΩ 上拉到 5V]
  |                                |
  +--- N-MOSFET 源极 (S)          +--- N-MOSFET 漏极 (D)
       N-MOSFET 栅极 (G) 接 3.3V
       N-MOSFET 体二极管方向: S → D
```

工作原理：

1. 3.3V 侧拉低 → MOSFET 导通 → 5V 侧也被拉低。
2. 5V 侧拉低 → 体二极管导通 → 3.3V 侧也被拉低（低于 VGS_th 后 MOSFET 也导通）。
3. 两侧都释放 → 各自上拉到各自 VDD。

特点：

1. 双向转换，自动检测方向。
2. 适合 I2C、1-Wire 等开漏总线。
3. 速度比专用芯片慢，受 MOSFET 和上拉电阻限制。
4. BSS138 是常用的电平转换 MOSFET。

#### 方法四：专用电平转换芯片

| 芯片 | 通道 | 方向 | 速度 | 特点 |
| --- | --- | --- | --- | --- |
| TXS0108E | 8 | 双向自动 | 60Mbps | I2C/SPI/GPIO 通用 |
| TXS0102 | 2 | 双向自动 | 24Mbps | I2C 双通道 |
| TXB0108 | 8 | 双向自动 | 100Mbps | 高速推挽信号 |
| SN74LVC245 | 8 | 单向（方向引脚控制） | 100Mbps+ | 高速总线 |
| SN74LVC1T45 | 1 | 双向（方向引脚控制） | 200Mbps | 单通道高速 |
| PCA9306 | 2 | 双向（I2C 专用） | 400kHz+ | I2C 专用 |

选型要点：

1. **方向**：双向自动（TXS/TXB）vs 方向引脚控制（74LVC 系列）。
2. **速度**：I2C 只需几百 kHz，SPI 可能需要几十 MHz。
3. **通道数**：SPI 需要 4 线，I2C 只需 2 线，并行总线需要 8/16/32 通道。
4. **供电**：两侧 VDD 是否需要独立供电。
5. **传播延迟**：高速信号需要关注 tpd。

### 5. TXS 和 TXB 系列的区别

| 特性 | TXS 系列 | TXB 系列 |
| --- | --- | --- |
| 信号类型 | 开漏 / 推挽 | 推挽 |
| 内部上拉 | 有（加速上升沿） | 无 |
| I2C 兼容 | ✅ 适合 | ❌ 不适合 |
| 速度 | 较低（60Mbps） | 较高（100Mbps） |
| 典型用途 | I2C、开漏信号 | SPI、UART、高速推挽 |

关键区别：TXS 内部有加速电路（one-shot + 上拉），适合 I2C 这种开漏信号；TXB 没有加速电路，适合推挽信号，但接 I2C 可能干扰总线。

### 6. 电源域和 IO 电压配置

SoC 通常有多个 IO 电源域：

```text
典型 SoC 电源域划分:

VDD_IO0 (3.3V): GPIO0~GPIO1, I2C, UART, SPI
VDD_IO1 (1.8V): GPIO2~GPIO3, DDR 接口
VDD_IO2 (3.3V): GPIO4, SD 卡接口
VDD_IO3 (1.8V): GPIO5, HDMI PHY
```

同一个电源域内的所有 IO 共享同一个 VDD，电平相同。不同电源域可以配不同电压。

软件工程师需要关注：

1. 每个外设引脚属于哪个电源域。
2. 该电源域的电压是多少。
3. 外设的 IO 电压是否跟电源域匹配。

### 7. 特殊接口的电平考虑

#### UART

1. UART TX/RX 是单端推挽信号。
2. 两端电压不同时需要电平转换。
3. RS-232 是 ±12V 电平，必须用 MAX3232 等转换芯片。

#### SPI

1. SPI 是高速推挽信号（CS、CLK、MOSI、MISO）。
2. 速度通常几 MHz 到几十 MHz。
3. 电平转换芯片的传播延迟必须足够小。
4. 推荐用 TXB0108 或 74LVC1T45。

#### I2C

1. I2C 是开漏信号，电平转换最简单。
2. 可以用 MOSFET 转换或 PCA9306。
3. 注意上拉电阻接在哪一侧（通常接各自 VDD 侧）。

#### JTAG / SWD

1. 调试接口通常是 1.8V 或 3.3V。
2. 调试器（J-Link / ST-Link）通常支持多电压。
3. 如果 SoC 是 1.8V IO，调试器要设为 1.8V 模式。

## 数据流 / 控制流 / 时序关系

### 电平转换对信号时序的影响

```text
无转换:
  发送方输出 → 接收方输入
  延迟: ~0 (直连)

有转换:
  发送方输出 → 电平转换芯片 → 接收方输入
  延迟: tpd (传播延迟，通常 1~10ns)

MOSFET 转换:
  发送方输出 → MOSFET + 上拉 → 接收方输入
  延迟: RC 时间常数 (可能几十到几百 ns)
```

传播延迟的影响：

1. SPI 等同步信号：延迟影响 setup/hold time 裕量。
2. UART 等异步信号：延迟影响波特率采样点。
3. I2C：延迟影响时钟拉伸和时序裕量。

## 最小可运行示例

### I2C 双向电平转换（MOSFET 方案）

```text
3.3V MCU (I2C Master)              5V 传感器 (I2C Slave)

VDD_3V3 ---[4.7kΩ]--- SDA_3V3 ---+--- SDA_5V ---[4.7kΩ]--- VDD_5V
                                   |
                              BSS138 MOSFET
                              G=VDD_3V3, S=SDA_3V3, D=SDA_5V

VDD_3V3 ---[4.7kΩ]--- SCL_3V3 ---+--- SCL_5V ---[4.7kΩ]--- VDD_5V
                                   |
                              BSS138 MOSFET
                              G=VDD_3V3, S=SCL_3V3, D=SCL_5V
```

### SPI 单向电平转换（TXB0108 方案）

```text
1.8V SoC (SPI Master)              3.3V Flash (SPI Slave)

SPI_CLK_1V8  ---[TXB0108 CH1]--- SPI_CLK_3V3
SPI_MOSI_1V8 ---[TXB0108 CH2]--- SPI_MOSI_3V3
SPI_MISO_1V8 ---[TXB0108 CH3]--- SPI_MISO_3V3
SPI_CS_1V8   ---[TXB0108 CH4]--- SPI_CS_3V3

TXB0108 VCCA = 1.8V
TXB0108 VCCB = 3.3V
```

### 设备树中的电平转换配置

```dts
/* I2C 总线经过电平转换后连接 5V 设备 */
&i2c0 {
    status = "okay";

    /* 3.3V 侧设备 */
    eeprom@50 {
        compatible = "atmel,24c02";
        reg = <0x50>;
    };

    /* 5V 侧设备（经过 MOSFET 电平转换） */
    sensor@48 {
        compatible = "ti,tmp102";
        reg = <0x48>;
    };
};
```

## 代码解读

### 1. 为什么 I2C 电平转换不需要改软件

I2C 电平转换是纯硬件行为，MOSFET 和上拉电阻自动完成电压转换。软件只需要按正常 I2C 操作，不需要知道中间有电平转换。

### 2. 为什么 SPI 电平转换要关注传播延迟

SPI 是高速同步总线，CLK 和数据之间有严格的时序关系。如果电平转换芯片的传播延迟不一致（比如 CLK 延迟 3ns、MOSI 延迟 5ns），可能导致 setup/hold time 不满足。选型时要确保 tpd 一致性。

### 3. 为什么设备树里不体现电平转换

电平转换芯片对软件是透明的，不需要在设备树里描述。但原理图上必须标明转换芯片的位置和连接关系，方便排障时追踪信号。

## 正确写法 vs 常见错误写法

| 场景 | 正确做法 | 常见错误 | 为什么错 |
| --- | --- | --- | --- |
| 3.3V → 5V TTL | 确认 5V 容忍后直连 | 不确认直接连 | 可能损坏 3.3V IO |
| 5V → 3.3V | 加电平转换或分压 | 直接连 | 5V 超过 3.3V IO 承受范围 |
| 1.8V → 3.3V | 加电平转换芯片 | 直连 | 1.8V 高电平不够 3.3V 识别 |
| I2C 电平转换 | MOSFET 或 PCA9306 | 用 TXB0108 | TXB 内部结构会干扰 I2C |
| SPI 电平转换 | TXB0108 或 74LVC | 用 MOSFET | MOSFET 速度不够 |
| 电源域配置 | 查 SoC 手册确认每个域的电压 | 假设所有 IO 都是 3.3V | 不同域可能不同电压 |

## 边界条件与适用范围

1. 电平转换芯片有最大速度限制，超过限制信号会失真。
2. MOSFET 电平转换的上升沿取决于上拉电阻和总线电容，总线电容大时上升沿很慢。
3. 电阻分压只适合低速单向信号，不适合 I2C、SPI 等双向或高速信号。
4. 某些 SoC 的 IO 可以软件配置电压（通过 VDDIO 寄存器），但大多数是硬件固定的。
5. 电平转换芯片本身也需要供电，两侧 VDD 必须正确连接。
6. 混合电压系统的 EMI 和信号完整性问题比单一电压系统更复杂。

## 常见坑与排查

| 现象 | 常见根因 | 优先验证方法 |
| --- | --- | --- |
| I2C 通信失败 | 电平转换芯片供电不对；上拉接错侧 | 万用表量两侧 SDA/SCL 电平 |
| SPI 数据错乱 | 电平转换延迟不一致 | 示波器对比两侧波形 |
| 3.3V IO 损坏 | 接了 5V 输出且不是 5V 容忍 | 查数据手册绝对最大额定值 |
| 1.8V 信号识别不到 | 没加电平转换 | 示波器看接收端电平 |
| 电平转换芯片发烫 | 两侧 VDD 接反或短路 | 检查供电和连接 |
| 信号上升沿太慢 | 上拉电阻太大或总线电容太大 | 示波器看上升沿时间 |

### 推荐排查顺序

1. 先确认两侧的 IO 电压值。
2. 再确认是否需要电平转换（查 VOH/VIH/VOL/VIL）。
3. 如果有电平转换芯片，确认供电和方向配置。
4. 用示波器对比转换前后的波形。
5. 检查上拉电阻值和位置。
6. 最后检查时序裕量。

## 工程落地建议

### 1. 建立电平兼容性检查清单

```text
新外设接入前检查:
  [ ] 外设 IO 电压是多少？
  [ ] SoC 对应引脚的电源域电压是多少？
  [ ] 发送方 VOH > 接收方 VIH？
  [ ] 发送方 VOL < 接收方 VIL？
  [ ] 接收方能否承受发送方的最大输出电压？
  [ ] 是否需要电平转换？转换方案是什么？
  [ ] 信号速度是否在转换芯片支持范围内？
```

### 2. 原理图上标注电平转换区域

```text
在原理图上用虚线框标注:
  - 3.3V 域
  - 1.8V 域
  - 5V 域
  - 电平转换芯片位置
```

方便排障时快速定位信号跨域位置。

### 3. 选型时留足裕量

1. 电平转换芯片速度至少是信号速度的 2 倍。
2. 电压承受至少留 20% 裕量。
3. 驱动能力至少是负载的 2 倍。

### 4. 高速信号的特殊考虑

1. SPI 超过 25MHz 时，电平转换芯片的传播延迟和 skew 很关键。
2. 差分信号（USB、HDMI、LVDS）有专用的电平转换方案，不能用普通转换芯片。
3. DDR 信号通常不做电平转换，而是确保 SoC 和 DDR 颗粒的 IO 电压一致。

## 性能、稳定性、可维护性影响

1. 电平转换芯片增加传播延迟，高速信号需要评估时序裕量。
2. 不加电平转换直连不同电压域，轻则通信失败，重则损坏芯片。
3. MOSFET 电平转换的上升沿速度受上拉电阻限制，I2C 快速模式需要更小电阻。
4. 电平转换芯片是额外器件，增加 BOM 成本和 PCB 面积，但避免返工成本更高。
5. 在原理图上清晰标注电平转换区域，能显著降低排障时间。

## 面试 / 问答怎么讲

### 30 秒版本

电平转换的核心是检查发送方输出电平是否在接收方识别范围内。3.3V 输出可以驱动 5V TTL 输入，但 5V 输出不能直接接 3.3V IO（除非 5V 容忍）。I2C 用开漏+MOSFET 转换最简单，SPI 用 TXB0108 等专用芯片。

### 3 分钟版本

从电平标准讲起：VOH/VIH/VOL/VIL 四个参数决定兼容性。然后分析常见组合：3.3V→5V TTL 可以，5V→3.3V 需要确认 5V 容忍，1.8V→3.3V 必须转换。再讲三种转换方法：开漏+上拉（I2C）、MOSFET（双向低速）、专用芯片（高速）。最后强调 I2C 用 TXS/PCA9306，SPI 用 TXB/74LVC。

### 10 分钟版本

可以系统展开：先详细讲电平标准和兼容性判断方法，画出 VOH/VIH/VOL/VIL 的关系图。然后逐个分析常见组合的兼容性。再讲四种转换方法的原理、优缺点和适用场景。然后讲选型要点：方向、速度、通道数、供电。再讲电源域划分和 IO 电压配置的关系。最后讲排障方法：示波器对比转换前后波形、检查上拉电阻值和位置。

## 实战练习

1. 查两个芯片的数据手册，提取 VOH/VIH/VOL/VIL 参数，判断能否直连。
2. 在原理图上找到一个电平转换芯片，确认它的供电、方向和连接关系。
3. 用示波器对比电平转换芯片两侧的波形，测量传播延迟。
4. 在 I2C 总线上用 MOSFET 做电平转换，观察不同上拉电阻值对上升沿的影响。
5. 设计一个 1.8V SoC 连接 3.3V SPI Flash 的电平转换方案，选型并说明理由。

## 关键要点

1. 电平兼容判断：VOH > VIH 且 VOL < VIL，才能直连。
2. 3.3V 输出可以驱动 5V TTL 输入；5V 输出接 3.3V 需确认 5V 容忍。
3. 1.8V 和 3.3V 之间通常需要电平转换。
4. I2C 用开漏+MOSFET 或 PCA9306；SPI 用 TXB0108 或 74LVC 系列。
5. TXS 适合 I2C（开漏），TXB 适合 SPI（推挽），不能混用。
6. 电平转换芯片有传播延迟，高速信号需要评估时序裕量。
7. 电源域决定 IO 电压，不同域的引脚不能直连。
