# 硬件-信号完整性基础

## 原始问题

为什么高速信号不能随便走线？反射是什么？为什么走线要做阻抗匹配？串扰是怎么产生的？差分信号为什么比单端信号抗干扰？眼图怎么看？软件工程师需要懂多少信号完整性？

## 先给结论

信号完整性的核心是"高速信号不再是简单的 0 和 1，而是电磁波在传输线上的传播"：

1. 当信号边沿足够快（上升时间 < 信号往返传播时间的 2 倍），走线就不再是导线，而是传输线。
2. 阻抗不匹配会导致信号反射，反射引起振铃、过冲、下冲，可能导致误触发和时序错误。
3. 串扰是相邻走线之间的电磁耦合，距离越近、并行越长、信号越快，串扰越严重。
4. 差分信号通过共模抑制抗干扰，是高速接口（USB、HDMI、PCIe、DDR 时钟）的主流选择。
5. 眼图是评估信号质量的综合工具，眼开度越大信号质量越好。

如果只知道"走线要短要直"，但讲不清反射、阻抗匹配、串扰和差分信号的原理，就还没有真正理解信号完整性。

## 这个知识解决什么问题

这篇笔记主要解决下面几类问题：

1. 高速接口（SPI、DDR、USB）通信不稳定，不知道是信号完整性问题还是软件问题。
2. 面试时被问"为什么要做阻抗匹配"，只能说出"防止反射"但讲不清原理。
3. 不理解差分信号为什么抗干扰，不知道差分走线规则。
4. 看到眼图不知道怎么判断信号质量。
5. 做板级调试时不知道什么时候该怀疑信号完整性。

它在 AI 时代依然重要，因为 AI 能帮你写驱动代码，但当高速总线通信不稳定时，AI 无法帮你判断是软件问题还是信号完整性问题。理解信号完整性基础后，你才能在"代码看起来没问题但通信就是不稳定"时，把怀疑方向转向物理层。

## 核心概念 / 本质机制

### 1. 什么时候需要关心信号完整性

判断标准：信号上升时间 vs 信号传播时间

```text
如果 上升时间(tr) < 2 × 传输线延迟(2×tpd)

则走线必须当作传输线处理，需要考虑信号完整性

其中:
  tpd = 走线长度 × 单位长度传播延迟
  典型 FR4 PCB: tpd ≈ 6.4 ns/m (约光速的 2/3)
```

粗略经验值：

| 信号边沿速度 | 需要考虑 SI 的走线长度 |
| --- | --- | --- |
| 1ns | > 2.5cm |
| 2ns | > 5cm |
| 5ns | > 12cm |
| 10ns | > 25cm |

现代 SoC 的 IO 上升时间通常在 0.5~2ns，所以几厘米以上的走线就需要考虑信号完整性。

### 2. 传输线和特性阻抗

当走线是传输线时，它有一个特性阻抗（Z0）：

```text
微带线 (Microstrip): 表面走线，一侧是空气一侧是介质

Z0 ≈ (87 / √(εr + 1.41)) × ln(5.98h / (0.8w + t))

其中:
  εr: 介质介电常数 (FR4 约 4.5)
  h: 走线到参考平面的距离
  w: 走线宽度
  t: 走线厚度
```

常见阻抗要求：

| 接口 | 特性阻抗 | 容差 |
| --- | --- | --- |
| USB 2.0 | 90Ω 差分 | ±15% |
| USB 3.0 | 90Ω 差分 | ±10% |
| HDMI | 100Ω 差分 | ±15% |
| PCIe | 85Ω 差分 | ±10% |
| DDR3/4 数据线 | 50Ω 单端 | ±10% |
| DDR3/4 时钟 | 100Ω 差分 | ±5% |
| 以太网 | 100Ω 差分 | ±5% |

### 3. 反射

反射的根本原因是阻抗不连续：

```text
信号从 Z1 走线进入 Z2 走线时:

反射系数: Γ = (Z2 - Z1) / (Z2 + Z1)

传输系数: T = 2 × Z2 / (Z2 + Z1)
```

典型反射场景：

1. **走线末端开路**（Z2 = ∞）：Γ = 1，信号完全反射，末端电压翻倍。
2. **走线末端短路**（Z2 = 0）：Γ = -1，信号负反射，末端电压为零。
3. **走线末端匹配**（Z2 = Z1）：Γ = 0，无反射，信号完全吸收。

反射导致的现象：

1. **振铃**：信号在走线两端来回反射，形成周期性振荡。
2. **过冲**：信号超过目标电平，可能损坏接收端。
3. **下冲**：信号低于地电平，可能导致闩锁效应。
4. **误触发**：振铃导致信号多次穿越阈值，接收端误判为多次跳变。

### 4. 阻抗匹配的方法

#### 端接匹配（最常用）

```text
源端匹配:
  发送端串联电阻 Rs = Z0 - Rdriver
  信号到达末端后反射回来，被源端电阻吸收
  优点: 功耗低
  缺点: 信号到达末端时只有一半幅度，需要反射才能达到满幅

末端并联匹配:
  接收端并联电阻 Rt = Z0 到 VDD 或 GND
  信号到达末端被电阻吸收，无反射
  优点: 信号到达即满幅
  缺点: 有直流功耗

末端戴维南匹配:
  接收端两个电阻分压到 VDD 和 GND
  等效阻抗 = Z0
  常用于 DDR 地址/命令线
```

#### 实际应用

| 接口 | 匹配方式 | 说明 |
| --- | --- | --- |
| SPI | 通常不需要 | 速度较低，走线短 |
| UART | 不需要 | 低速异步 |
| I2C | 不需要 | 开漏 + 上拉，天然匹配 |
| DDR 数据线 | 末端 ODT | DDR3/4 内置端接电阻 |
| DDR 地址/命令线 | 戴维南匹配 | 外部电阻分压 |
| USB | 源端匹配 | 收发器内置匹配 |
| PCIe | 末端匹配 | 接收端内置 |

### 5. 串扰

串扰是相邻走线之间的电磁耦合：

```text
攻击线 (Aggressor): 信号变化的走线
受害线 (Victim):    被耦合影响的走线

近端串扰 (NEXT): 靠近发送端的耦合噪声
远端串扰 (FEXT): 靠近接收端的耦合噪声
```

串扰的耦合机制：

1. **容性耦合**：两根走线之间的寄生电容，攻击线电压变化通过电容耦合到受害线。
2. **感性耦合**：两根走线之间的互感，攻击线电流变化通过磁场耦合到受害线。

降低串扰的方法：

1. 增大走线间距：间距 ≥ 3 倍线宽时串扰显著降低。
2. 减少并行长度：并行走线越短串扰越小。
3. 加地线屏蔽：在两条信号线之间加地线（Guard Trace）。
4. 使用差分信号：差分对对外部耦合是共模的，接收端可以抑制。
5. 减小信号边沿速率：边沿越慢，高频分量越少，串扰越小。

### 6. 差分信号

差分信号用两根互补的线传输一个信号：

```text
单端信号:  信号线 D+ 相对于 GND 的电压表示 0/1

差分信号:  D+ 和 D- 的电压差表示 0/1
  D+ = Vcm + Vd/2
  D- = Vcm - Vd/2
  Vdiff = D+ - D- = Vd

共模电压: Vcm = (D+ + D-) / 2
```

差分信号抗干扰的原理：

1. 外部噪声对 D+ 和 D- 的耦合是近似相等的（共模干扰）。
2. 接收端只看差值 Vdiff = D+ - D-，共模干扰被减掉。
3. 差分对的两根线紧挨着走，确保耦合到相同的噪声。

差分走线规则：

1. **等长**：两根线长度差通常要求 < 5mil（高速接口更严），否则信号到达时间不同，产生共模分量。
2. **等距**：两根线间距保持一致，确保特性阻抗均匀。
3. **紧耦合**：间距通常等于线宽，太远会降低共模抑制能力。
4. **同层走线**：两根线必须在同一层，过孔会引入不连续性。
5. **避免跨分割**：两根线下方的参考平面必须完整，跨分割会破坏返回路径。

### 7. 返回电流和参考平面

信号在走线上传播时，返回电流在参考平面（地平面或电源平面）上流动：

```text
低速信号: 返回电流走最短路径（直线回到源端）
高速信号: 返回电流紧跟信号路径（在走线下方的参考平面上）
```

返回路径不连续的后果：

1. 走线跨越参考平面分割时，返回电流必须绕路，形成大的电流环路。
2. 大环路增加 EMI 辐射和串扰。
3. 环路电感增大，信号质量下降。

工程规则：

1. 高速信号走线下方的参考平面必须完整。
2. 如果必须跨分割，在跨越处放去耦电容（连接两个平面）。
3. 换层时，在过孔旁边放地过孔（Stitching Via），提供返回路径。

### 8. 眼图

眼图是把信号的所有比特周期叠加在一起显示的图形：

```text
         ___     ___     ___
        |   |   |   |   |   |
     ___|   |___|   |___|   |___

        ↑ 眼图就是把所有这样的周期
          叠加在一起看

理想眼图:  "眼睛" 大而清晰
劣化眼图:  "眼睛" 变小或闭合
```

眼图的关键参数：

| 参数 | 含义 | 影响 |
| --- | --- | --- |
| 眼高 | 信号高低电平的差值（扣除抖动） | 眼高越大，噪声裕量越大 |
| 眼宽 | 信号稳定的时间窗口 | 眼宽越大，时序裕量越大 |
| 抖动 | 信号边沿的时间不确定性 | 抖动越大，眼宽越小 |
| 上升/下降时间 | 信号边沿的快慢 | 影响眼图的斜率 |
| 过冲/下冲 | 信号超过目标电平的量 | 过大可能损坏器件 |

眼图判断经验：

1. 眼开度 > 70%：信号质量良好。
2. 眼开度 50%~70%：信号质量一般，需要关注。
3. 眼开度 < 50%：信号质量差，可能误码。
4. 眼图闭合：信号无法正确接收。

### 9. 信号完整性和软件的关系

软件工程师需要关注信号完整性的场景：

1. **高速总线调试**：SPI 超过 25MHz、DDR、USB、PCIe 通信不稳定时，可能是 SI 问题。
2. **时序裕量不足**：setup/hold time 不满足，可能是反射或串扰导致。
3. **偶发误码**：某些特定数据模式触发 SI 问题（如连续 0→1 跳变后读错）。
4. **EMI 超标**：GPIO 输出速度设太高、信号返回路径不完整导致辐射超标。
5. **设备树配置**：DDR 频率、驱动强度、ODT 配置都影响 SI。

## 数据流 / 控制流 / 时序关系

### 信号从发送到接收的完整路径

```text
发送端驱动器
  |
  V
发送端匹配电阻 (可选)
  |
  V
PCB 走线 (传输线)
  |  ← 传播延迟 tpd
  |  ← 可能遇到阻抗不连续 (过孔、连接器)
  |  ← 可能受到相邻走线串扰
  |
  V
接收端匹配电阻 (可选)
  |
  V
接收端采样
  |  ← 需要满足 setup/hold time
  |  ← 受抖动和噪声影响
  |
  V
数据被正确接收 (或误码)
```

### 反射的时序过程

```text
t=0:     发送端发出信号，幅度 V/2 (源端匹配)
t=T:     信号到达接收端，反射发生
t=T:     接收端看到 V/2 + V/2 = V (直射 + 反射叠加)
t=2T:    反射信号回到发送端，被源端电阻吸收
t=2T+:   信号稳定
```

## 最小可运行示例

### DDR 驱动强度配置（设备树）

```dts
/* DDR 控制器的驱动强度和 ODT 配置 */
/* 驱动强度影响信号边沿速率和反射 */
/* ODT (On-Die Termination) 是芯片内部的端接电阻 */

&dmc {
    rockchip,pd-idle-ns = <80>;
    rockchip,sr-idle-ns = <1024>;
    rockchip,sr-mc-gate-idle-ns = <4096>;

    /* 驱动强度: 影响输出阻抗和信号边沿 */
    rockchip,ddr-speed-bin = <21>;

    /* ODT 配置: 写操作时 DRAM 端的端接电阻 */
    /* 0=禁用, 1=120Ω, 2=60Ω, 3=40Ω, 4=30Ω, 5=24Ω */
    rockchip,phy-drv-clk = <1>;     /* 时钟线驱动强度 */
    rockchip,phy-drv-ca  = <1>;     /* 命令/地址线驱动强度 */
    rockchip,phy-drv-dq  = <1>;     /* 数据线驱动强度 */
    rockchip,phy-odt-dq  = <1>;     /* 数据线 ODT 值 */
};
```

### GPIO 驱动强度配置

```c
/* 降低 GPIO 输出速度减少 EMI 和反射 */
/* 速度越高边沿越快，高频分量越多 */

/* STM32 GPIO 输出速度配置 */
#define GPIO_OSPEEDR_LOW       0x00  /* < 2MHz, EMI 最小 */
#define GPIO_OSPEEDR_MEDIUM    0x01  /* 2~25MHz */
#define GPIO_OSPEEDR_HIGH      0x02  /* 25~50MHz */
#define GPIO_OSPEEDR_VERY_HIGH 0x03  /* > 50MHz, EMI 最大 */

static void spi_clk_config(void)
{
    /* SPI CLK 走线较长时，降低输出速度减少反射 */
    GPIOA_OSPEEDR = (GPIOA_OSPEEDR & ~(3 << (5 * 2)))
                  | (GPIO_OSPEEDR_HIGH << (5 * 2));
}
```

### 用示波器检查信号质量

```text
检查步骤:
1. 探头点到信号接收端
2. 触发设置: 边沿触发，阈值设在 VDD/2
3. 观察波形:
   - 有无明显振铃？→ 可能是阻抗不匹配
   - 有无过冲超过 VDD + 0.5V？→ 可能损坏器件
   - 上升/下降时间是否合理？→ 太快可能反射，太慢可能时序不满足
4. 如果支持眼图模式，打开眼图观察眼开度
```

## 代码解读

### 1. 为什么 DDR ODT 配置影响信号完整性

DDR 数据线是双向的，写操作时 DRAM 端接收，读操作时控制器端接收。ODT 是 DRAM 芯片内部的端接电阻，写操作时开启，吸收到达 DRAM 端的信号，防止反射。ODT 值选择不当会导致反射严重或信号幅度不足。

### 2. 为什么 GPIO 输出速度不是越快越好

输出速度越高，信号边沿越陡，高频分量越丰富。如果走线较长且没有做阻抗匹配，陡边沿的信号会产生严重反射。降低输出速度（减慢边沿）可以减少反射和 EMI，代价是信号建立时间变长。

### 3. 为什么 SPI 速度高时需要关注 SI

SPI CLK 和 MOSI/MISO 是推挽高速信号。当 SPI 时钟超过 25MHz 时，信号边沿通常在 1~2ns，如果走线超过 5cm 且没有阻抗匹配，反射可能导致时钟和数据信号振铃，接收端在采样点读到错误数据。

## 正确写法 vs 常见错误写法

| 场景 | 正确做法 | 常见错误 | 为什么错 |
| --- | --- | --- | --- |
| 高速走线 | 做阻抗匹配 | 随意走线 | 反射导致信号劣化 |
| 差分走线 | 等长等距同层 | 不等长或不同层 | 产生共模分量，降低抗干扰能力 |
| GPIO 速度 | 根据走线长度选择 | 全部设最高速 | 不必要的 EMI 和反射 |
| DDR ODT | 根据仿真和测试选择 | 不开 ODT | 写操作时 DRAM 端反射严重 |
| 跨分割走线 | 避免或加去耦电容 | 直接跨分割 | 返回路径中断，EMI 增加 |
| 高速信号过孔 | 旁边加地过孔 | 只打信号过孔 | 返回路径不连续 |

## 边界条件与适用范围

1. 这篇笔记面向软件工程师的信号完整性入门，不是 SI 工程师的专业课程。
2. 低速信号（UART、I2C、低于 10MHz 的 SPI）通常不需要考虑 SI。
3. 信号完整性问题通常需要仿真工具（HyperLynx、SIwave）和实际测量结合分析。
4. 不同 PCB 材料的介电常数和损耗不同，高速设计需要指定材料。
5. 软件工程师的 SI 知识主要用于：判断问题方向、理解硬件约束、配合 SI 工程师调试。

## 常见坑与排查

| 现象 | 常见根因 | 优先验证方法 |
| --- | --- | --- |
| 高速 SPI 数据偶发错误 | 反射/串扰导致采样点信号不稳定 | 示波器看接收端波形 |
| DDR 初始化偶发失败 | 地址/命令线 SI 问题 | 降低频率测试 |
| USB 枚举失败 | 差分对不等长/阻抗不匹配 | 眼图测试 |
| EMI 超标 | 信号返回路径不完整 | 近场探头扫描 |
| 特定数据模式出错 | 串扰（特定跳变模式触发） | 改数据模式测试 |
| 过冲损坏器件 | 没有端接或驱动强度过大 | 示波器看信号幅度 |

### 推荐排查顺序

1. 先降低频率/速度，看问题是否消失（频率降低 → SI 问题减轻）。
2. 再用示波器看接收端波形，确认有无振铃/过冲。
3. 再检查 PCB 走线是否做了阻抗匹配。
4. 再检查差分对是否等长等距。
5. 再检查返回路径是否完整。
6. 最后用眼图评估信号质量。

## 工程落地建议

### 1. 软件工程师的 SI 自查清单

```text
高速接口调试时:
  [ ] 信号频率是多少？走线多长？需要考虑 SI 吗？
  [ ] PCB 是否做了阻抗控制？差分对是否等长？
  [ ] 驱动强度和 ODT 配置是否合理？
  [ ] 降低频率后问题是否消失？
  [ ] 示波器看到的波形是否正常？
```

### 2. 和 SI 工程师协作的要点

1. 提供准确的信号频率、走线长度和连接拓扑。
2. 提供驱动强度、ODT 等可配置参数的范围。
3. 配合做眼图测试和误码率测试。
4. 报告问题时的数据模式（某些 SI 问题只在特定数据模式下出现）。

### 3. 设备树中影响 SI 的配置项

```dts
/* 驱动强度: 影响信号边沿速率 */
/* ODT: 影响端接匹配 */
/* 频率: 影响信号频谱和损耗 */

&spi0 {
    spi-max-frequency = <50000000>;  /* 降低频率改善 SI */
};

&emmc {
    mmc-ddr-1_8v;                    /* DDR 模式需要更好的 SI */
    mmc-hs200-1_8v;                  /* HS200 需要严格的阻抗控制 */
};
```

## 性能、稳定性、可维护性影响

1. SI 问题通常表现为偶发错误，极难定位，是系统稳定性的隐形杀手。
2. 降低频率可以缓解 SI 问题，但牺牲性能。
3. 正确的阻抗匹配和端接能显著提高高速接口的可靠性。
4. 差分信号的抗干扰能力使高速长距离传输成为可能。
5. SI 问题在原型阶段可能不明显，量产时因为 PCB 批次差异可能暴露。

## 面试 / 问答怎么讲

### 30 秒版本

信号完整性是高速信号在传输线上的行为。阻抗不匹配导致反射，反射引起振铃和误码。串扰是相邻走线的电磁耦合。差分信号通过共模抑制抗干扰。眼图是评估信号质量的综合工具，眼开度越大越好。

### 3 分钟版本

从传输线概念讲起：当信号边沿快到一定程度，走线变成传输线，有特性阻抗。阻抗不连续时信号反射，反射系数 Γ=(Z2-Z1)/(Z2+Z1)。然后讲匹配方法：源端串联、末端并联、ODT。再讲串扰：容性和感性耦合，增大间距和减少并行长度可以降低。再讲差分信号：两根线等长等距，共模噪声被接收端减掉。最后讲眼图：所有比特周期叠加，眼开度反映信号质量。

### 10 分钟版本

可以系统展开：先从传输线理论讲起，推导特性阻抗和反射系数。然后详细讲各种匹配方法的原理和适用场景。再讲串扰的容性和感性耦合机制，以及近端和远端串扰的区别。再讲差分信号的数学原理和走线规则。再讲返回电流和参考平面的关系。最后讲眼图的测量方法和参数解读，以及软件工程师如何配合 SI 调试。

## 实战练习

1. 用示波器观察一个 SPI CLK 信号，在走线较长和较短时分别看波形差异。
2. 故意把 SPI 频率从 10MHz 提高到 50MHz，观察是否出现数据错误。
3. 在 PCB 上找到一对差分走线（USB 或 HDMI），测量两根线的长度差。
4. 用示波器的眼图功能测量一个高速信号，判断眼开度是否合格。
5. 修改设备树中的 DDR ODT 配置，观察对稳定性的影响。

## 关键要点

1. 信号上升时间足够快时，走线是传输线，需要考虑信号完整性。
2. 阻抗不匹配导致反射，反射系数 Γ=(Z2-Z1)/(Z2+Z1)。
3. 匹配方法：源端串联、末端并联、ODT，根据接口选择。
4. 串扰是相邻走线的电磁耦合，增大间距和减少并行长度可以降低。
5. 差分信号通过共模抑制抗干扰，走线必须等长等距同层。
6. 返回电流紧跟信号路径，参考平面必须完整。
7. 眼图评估信号质量，眼开度越大越好。
8. 软件工程师的 SI 知识主要用于判断问题方向和配合调试。
