# 外设-DAC基础

## 原始问题

DAC 到底是什么？为什么它看起来只是“把数字变电压”，但实际项目里总会碰到输出不线性、台阶噪声、更新抖动、驱动能力不足、参考漂移等问题？应该怎样系统掌握 DAC，而不是只会写一个寄存器值？

## 先给结论

DAC 的本质是“把离散数字码映射为对应模拟电压/电流”，它输出的是可控模拟量，但精度和动态表现受参考源、更新时序、负载与后级滤波共同决定。

先记住下面几个结论：

1. DAC 输出精度首先受参考电压稳定性约束。
2. DAC 输出是台阶波，连续波形通常需要更新策略和滤波配合。
3. 分辨率决定最小步进，但真实有效精度还受噪声和非线性影响。
4. 负载特性和缓冲放大器决定输出是否“看起来对”。
5. 真实工程里 DAC 常和定时器、DMA 联动，而不是 CPU 单点写值。

如果只能背“12 位 DAC 范围 0~4095”，却讲不清零点误差、增益误差、建立时间、输出缓冲和采样保持系统耦合问题，就说明这部分还没有真正掌握。

## 这个知识解决什么问题

1. 需要输出可调模拟量（偏置、电压设定、波形）但不知道如何稳定实现。
2. 输出电压理论正确，实测却偏差大或动态不平滑。
3. 面试时能说 DAC 用途，但讲不清工程落地链路。

## 核心概念 / 本质机制

### 1. DAC 的基本映射关系

常见换算：

1. `Vout = Vref * code / (2^N - 1)`。

其中：

1. `N` 是分辨率。
2. `code` 是数字输入码。

### 2. 静态指标

常见关注：

1. 零点误差（offset）。
2. 增益误差（gain）。
3. INL / DNL（线性与单调性表现）。

这些决定“设定值是否准”。

### 3. 动态指标

常见关注：

1. 建立时间（step 后多久稳定）。
2. 毛刺能量（码值切换瞬间尖峰）。
3. 更新抖动（触发不稳导致波形抖）。

这些决定“变化过程是否稳”。

### 4. 输出缓冲和负载

DAC 引脚直接带负载常受限。

常见做法：

1. 用运放缓冲提升驱动能力。
2. 设计 RC 滤波抑制台阶高频分量。
3. 对高精度场景做隔离与参考优化。

### 5. DAC 与定时器 / DMA 联动

输出波形（如正弦、锯齿）时，常见链路：

1. 定时器提供固定更新节拍。
2. DMA 按查表序列把码值搬到 DAC。
3. DAC 按节拍输出。

这样比软件轮询更稳。

## 数据流 / 控制流 / 时序关系

```text
上层给目标模拟量/波形参数
-> 换算为 DAC 码值序列
-> 定时器触发更新
-> DAC 输出台阶模拟量
-> 后级滤波/缓冲
-> 负载获得目标电压/电流
```

## 最小可运行示例

```c
#define DAC_BASE            0x40007400
#define DAC_CR              (*(volatile unsigned int *)(DAC_BASE + 0x00))
#define DAC_DHR12R1         (*(volatile unsigned int *)(DAC_BASE + 0x08))

#define DAC_CR_EN1          (1U << 0)
#define DAC_MAX_CODE        4095U
#define DAC_VREF_MV         3300U

static void dac_init(void)
{
    DAC_CR |= DAC_CR_EN1;
}

static void dac_set_mv(unsigned int mv)
{
    unsigned int code;

    if (mv > DAC_VREF_MV)
        mv = DAC_VREF_MV;

    code = mv * DAC_MAX_CODE / DAC_VREF_MV;
    DAC_DHR12R1 = code;
}
```

## 正确写法 vs 常见错误写法

| 场景 | 正确写法 | 常见错误写法 | 为什么错 |
| --- | --- | --- | --- |
| 电压映射 | 明确 Vref 和分辨率换算 | 写死经验值 | 板级偏差大 |
| 动态输出 | 定时器/DMA 固定节拍更新 | 任务里随缘写值 | 抖动明显 |
| 负载驱动 | 评估输出阻抗与缓冲 | DAC 直带重负载 | 幅值失真 |

## 常见坑与排查

1. 输出幅值偏差大：先查 Vref 和标定。
2. 波形边缘毛刺明显：查更新时序与滤波。
3. 低频纹波大：查电源噪声和地回路。

## 工程落地建议

1. DAC 驱动层只负责稳定输出码值。
2. 波形层负责查表和节拍。
3. 业务层只描述目标量，不直接碰寄存器。

## 关键要点

1. DAC 输出精度先看参考，再看换算。
2. 连续波形靠“节拍+查表+滤波”闭环实现。
3. 负载与后级模拟电路决定最终可用性。
